# Source artwork

`archive/` retains original and retired images outside Vite's `public/` directory.
These files are kept for future editing but are not copied into the deployed site.

The September 2026 performance cleanup moved 18 files (23,187,735 bytes) after
checking frontend source references and the published Work summaries/galleries.
Active WebP variants, responsive sources, placeholders, fonts and icons remain in
their existing locations. Git history records each previous public path.
