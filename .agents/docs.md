# Docs Rules

## Changelog

- Do not update the changelog while work is in progress.
- Add a changelog entry only when completed work is ready to push.
- Update the changelog before pushing the branch and opening its pull request.
- Add one concise entry per affected area for each pull request.
- Describe the completed outcome, not the implementation process.
- Do not add an entry for changelog-only edits.
- Create an area changelog only when that area ships its first change.

Follow `docs/changelog/README.md` for the entry format.
