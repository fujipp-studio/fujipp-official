# AI Agent Instructions

These rules apply to every AI agent working in this repository.

## Core Rules

- Work only within the assigned scope.
- Do not implement extra or speculative future work.
- You may recommend the best approach, but do not implement it without approval.
- Report completed work concisely. Provide details only when asked.
